- **学位数**: Phase1.taken + Phase2A.taken + Phase2B.taken + Phase2C.taken + Phase2CS.vacancy
- **剩余名额**: 学位数 - 录取数
- **未录取数**: max(申请数 - 学位数, 0)
- **竞争比率**: 申请数 / 学位数，反映区域竞争激烈程度
- **成功率**: 录取数 / 申请数
- **学位利用率**: 录取数 / 学位数
